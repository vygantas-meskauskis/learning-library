# Learning library

This repository is the canonical home for the learning courses. Add each new course under `courses/<slug>/`.

- **Adding or updating a course:** before editing, follow [Add or update a course](README.md#add-or-update-a-course), the authoritative procedure for course layout, homepage registration, reader navigation, and validation.
- **Changing shared assets, website staging, or workflows:** first read [Repository layout](README.md#repository-layout). For .NET automation or Azure deployment work, also read [Migration and automation notes](MIGRATION.md).
- Keep changes within the requested course or shared surface. Preserve other courses and existing reader anchors unless their modification is part of the task.
- `AGENTS.md` files in course `toolkit/` and `templates/` directories are downloadable teaching examples, not library-wide policy. Preserve them as course content.
- Course creation alone does not authorize committing or publishing. Follow [Publication](README.md#publication); commit, push, or deploy only when explicitly requested.
